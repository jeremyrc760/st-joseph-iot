## Terraform Import Strategy Recommendation

The next Terraform phase should avoid taking ownership of every related AWS resource at once. The ECS service depends on networking, load balancing, IAM, ACM, DNS, Secrets Manager, and CloudWatch resources. Some of those resources have `sonarqube` names and may be shared or legacy-managed.

Recommended first import candidates:

```text
aws_ecs_cluster.main
aws_ecs_task_definition.backend
aws_ecs_service.backend
aws_cloudwatch_log_group.backend
```

Reason:

```text
These resources are directly tied to the St. Joseph IoT backend runtime and are the safest first ECS ownership boundary.
```

Recommended data block candidates at first:

```text
aws_vpc.existing
aws_subnets.existing_public
aws_security_group.alb
aws_security_group.ecs_service
aws_lb.existing
aws_lb_listener.https
aws_lb_target_group.backend
aws_lb_listener_rule.backend_host
aws_iam_role.ecs_task_execution
aws_acm_certificate.api
aws_secretsmanager_secret.backend
```

Reason:

```text
These resources are existing dependencies. Several are shared or legacy-named, especially the ALB and public networking resources. Referencing them with data blocks lowers the chance that Terraform will accidentally try to modify shared infrastructure.
```

Resources to avoid managing until ownership is clear:

```text
VPC
Subnets
Route tables
Internet Gateway
ALB
ALB listener
ALB listener default action
SonarQube target group
ACM certificate
Route 53 hosted zone or records
Secrets Manager secret values
IAM policies used by other workloads
```

Suggested import order:

```text
1. aws_cloudwatch_log_group.backend
2. aws_ecs_cluster.main
3. aws_ecs_task_definition.backend
4. aws_ecs_service.backend
```

After each import, run:

```bash
terraform plan
```

Stop if Terraform shows unexpected create, update, or destroy actions.

Important notes:

```text
Do not store secret values in Terraform.
Do not import the ALB until it is clear whether it belongs to this app or is shared with SonarQube.
Do not run terraform apply during import planning.
Expect aws_ecs_task_definition to be sensitive to container definition JSON formatting and image tag changes.
```
